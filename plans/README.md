# plans/

Working memory for this repo: plans, queues, open questions, decisions.
Project knowledge lives here, not in agent memory.

## Contents

| File | Purpose |
|------|---------|
| `next-up.md` | Ordered work queue + done log |
| `open-questions.md` | Unresolved questions blocking or shaping work |
| `decisions/` | One file per structural/architectural decision |
| `2026-07-20-stability-performance-review.md` | Full critical review + phased remediation plan |

## Status vocabulary

`planned` → `in-progress` → `done` (or `dropped` with reason).

## Conventions

- One plan file per initiative, date-prefixed: `YYYY-MM-DD-slug.md`.
- Decisions: `decisions/YYYY-MM-DD-slug.md`, short — context, decision, consequences.
- Keep `next-up.md` current; move finished items to its `## Done` section.
